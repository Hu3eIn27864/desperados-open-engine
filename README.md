# Desperados Open Engine

A clean-room, cross-platform reimplementation of the runtime for *Desperados: Wanted Dead or Alive*.

## Project status

Early foundation stage. The project aims to replace the original executable while loading game data from a legally obtained local installation.

## Principles

- Clean-room implementation; no copied or adapted third-party engine code.
- Original game assets are not distributed by this repository.
- C++20, SDL3 and CMake.
- Targets: Windows, Linux and macOS.
- No map or mission editor is planned.

## Build

The build instructions will be added with the initial CMake setup.
