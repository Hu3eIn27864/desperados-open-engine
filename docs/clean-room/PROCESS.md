# Clean-room development process

This project is developed independently. Do not copy, adapt, translate or port
source code from other game engines or reverse-engineering projects.

## Research and implementation
- Record externally observable behavior and file-format facts separately from implementation code.
- Prefer lawful interoperability research and independently authored tests.
- Keep research notes factual, sourced and free of copied implementation text.
- Implement parsers from independently derived specifications.
- Use synthetic fixtures for tests; do not commit copyrighted game assets.
- When provenance is uncertain, do not add material until reviewed.

## Repository content
Do not commit original game executables, archives, maps, scripts, images, music,
video, fonts, extracted assets or user installation paths.

The project license covers only original project code and documentation. It
does not grant rights to third-party game data or trademarks.
